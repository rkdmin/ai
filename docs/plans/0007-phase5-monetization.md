# Plan 0007 · Phase 5 — 수익화 (광고 + 카드 잠금)

> 결정 배경: [ADR 0007](../decisions/0007-phase5-monetization.md) · 전체 진행 상황: [ROADMAP](../ROADMAP.md)

체크 표기는 [`README.md`](./README.md) 의 규약을 따른다.

## 완료 기준

첫 수익이 발생하고 API 비용을 상회한다.

## 구현

### 5-6. 테스트 전략
- [ ] 광고 시청 전/후 카드 잠금 상태 회귀 테스트
- [ ] 게스트/로그인 사진 생성 권한 변화 integration test
- [ ] 쿠팡 링크 생성 규칙 unit test 추가
- [ ] 메이크업 카드 제품 블록 노출/CTA 클릭 E2E 추가
- [ ] 사진 생성 일일 제한 초과 시나리오 테스트 추가

### 핵심 체크
- [ ] 카드 잠금 UX 구현 (Rank 1·2 블러 + 자물쇠)
- [ ] AdMob 보상형 광고 연동
- [ ] AdMob 배너 광고 연동
- [ ] 광고 시청 후 카드 해제 흐름 동작
- [ ] `card_unlock_ad_viewed`, `card_unlocked` 트래킹 추가
- [ ] 첫 달 수익이 API 비용을 상회하는지 확인
- [ ] 광고/잠금 해제 E2E·integration 테스트 그린

## 사용자 직접 확인

> 코드로 검증할 수 없어 사람이 직접 해봐야 하는 항목이다.

### 카드 잠금
- [ ] v1.1 빌드에서 카드 목록 → Rank 1·2 카드가 블러 + 자물쇠로 보임
- [ ] Rank 3, Avoid 카드는 잠금 없이 바로 보임
- [ ] 잠긴 카드 탭 → "광고 시청 후 확인" 모달 노출
- [ ] 광고 끝까지 시청 → 해당 카드만 해제, 다른 잠긴 카드는 여전히 잠금
- [ ] 광고 도중 닫음 → 카드 해제 안 됨
- [ ] 앱 종료 후 재실행 → 다시 잠금 적용 (세션 종료 룰)

### 광고 노출 위치
- [ ] 카드 목록 하단 배너가 추천 카드 본문을 침범하지 않음
- [ ] 분석 로딩 중에 광고가 안 뜸
- [ ] 광고 영역과 추천 이유 텍스트가 시각적으로 분리됨

### 쿠팡 파트너스 (v1.0부터 적용)
- [ ] 메이크업 카드 상세 하단 추천 제품 블록 2~4개 노출
- [ ] 쿠팡 고지 문구가 CTA 근처에 있음
- [ ] "쿠팡에서 보기" → 시스템 브라우저로 외부 이동
- [ ] 쿠팡 링크 클릭 시 `coupang_link_click` 이벤트가 PostHog에 들어옴

### 사진 생성 사용량
- [ ] 같은 분석에서 헤어 카드 사진 1장 생성 → 같은 카드 다시 누름 → 즉시 캐시 응답 (대기 없음)
- [ ] 일일 5회 한도까지 새 분석으로 사진 생성 → 6회째 안내 UI

### 트래킹
- [ ] PostHog 대시보드에서 v1.0 이벤트 4종 + v1.1 이벤트 2종이 모두 들어오는지 확인
