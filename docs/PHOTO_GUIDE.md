# 📸 촬영 가이드

정확한 분석을 위해 아래 가이드에 맞춰 사진을 찍어주세요.
촬영 각도·거리에 따라 분석 정확도가 크게 달라집니다.

> **이 문서는 전체 기준(reference)이고, 앱은 그중 핵심만 축약해 보여준다.**
> `PhotoUpload.jsx` 의 DO/DON'T 타일 4개가 그것이다 —
> 포니테일·민소매 / 후면 카메라(광각 ✗) / 앞머리·마스크 ✗ / 필터·역광 ✗.
> 앱 문구를 바꾸면 이 문서와 어긋나지 않는지 함께 확인한다.
>
> `src/data/촬영가이드 *.png` 두 장은 **앱 코드에서 참조되지 않는다** (git 에는 있음).

## 📌 공통 사항 (모든 사진 동일 적용)

### 👗 의상
- **민무늬 검정 민소매** 착용 (어깨·쇄골이 보여야 함)
- 패턴·로고·색상 있는 옷 X

### 💇 헤어
- **앞머리까지 완전히 올려서 포니테일로 묶기**

### 🖼 배경 & 조명
- **민무늬 밝은 배경** (살구색 제외)
- 배경에 그림자가 지지 않도록 주의
- 조명은 **앞쪽**에 배치 (역광 X)

### 📱 카메라
- **후면 카메라 / 기본 모드** 사용
- **광각(0.5×) 금지** — 얼굴 왜곡 발생
- 갤럭시 울트라 기종 사용 금지
- 카메라를 기울이지 말고 **수직** 유지

### 📐 거리 & 프레임
- 거리: 약 60cm (팔 길이)
- 렌즈 위치: 눈과 입술 사이
- 프레임: 어깨 양옆에 여백 나오게
- 자세: 차렷 / 무표정

## 🚧 앱이 실제로 막는 것 (`PhotoUpload.jsx`)

가이드 위반은 앱이 막지 않는다. 아래 두 가지만 코드로 강제된다.

- **10MB 초과 업로드 거부** — "사진 용량은 10MB 이하만 업로드할 수 있어요."
- **분석 동의 체크 필수** — 체크 없이는 NEXT 진행 불가

얼굴이 검출되지 않으면 백엔드가 Gemini 호출 없이 400 으로 끊고 앱은 `error_face` 화면을 띄운다.
단 **일러스트·3D 렌더링·마네킹은 얼굴로 인식되어 통과**하므로, 실사 여부는 분석 프롬프트가 거른다.

## ⚠️ 자주 하는 실수

- 앞머리를 내린 채 촬영 → 이마·얼굴형 분석 불가
- 광각 카메라 사용 → 얼굴 비율 왜곡
- 마스크·선글라스 착용 → 이목구비 분석 불가
- 어두운 배경 또는 역광 → 윤곽 인식 오류
